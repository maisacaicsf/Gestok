GESTOK - REDES SOCIAIS

Página das redes sociais oficiais do Gestok.

Redes incluídas:
- Instagram
- Facebook
- TikTok
- YouTube

WhatsApp e LinkedIn foram removidos.

Para adicionar os links posteriormente, edite o arquivo script.js:

const REDES_GESTOK = {
    instagram: "https://...",
    facebook: "https://...",
    tiktok: "https://...",
    youtube: "https://..."
};

A página não salva dados por loja e não usa Firestore para os links.
